# codyssey_3
코디세이 3주 과제
```
1.프로그램 실행방법: 파이썬 가상환경(.venv)에서 py. main.py 입력하여 실행
```
```
2.실행 모드 2가지
   
   2-1. 사용자 입력 모드: 목록에서 1을 누르면, 3 x 3 행렬 필터 2개와 패턴을 직접 입력받아 만들고 MAC연산을 시킵니다. 결과로는
        해당 두 개의 필터 MAC 연산의 성능을 보여주고 판정 결과를 보여줍니다.

   2-2. json 분석 모드: 목록에서 2를 누르면, data.json 내부에 저장되어 있는 필터와 패턴 행렬로 MAC연산이 진행되고 판정결과와 실패목록
        연산 성능을 보여줄 수 있습니다.
```
```
3. 구현 요약

   3-1. 라벨정규화: json파일에서 읽는 +, x 에 대해 + 는 Cross, x 는 X로 변환하여 표기방식이 달라 분석과정 중 실패하는 것을 방지

   3-2. MAC 연산 구현 개요:

        mac_operation() 함수가 있습니다. 매개변수로 패턴 행렬 리스트와 필터 행렬 리스트를 받습니다. 이 두 리스트는 같은 행렬의 크기로
        어느 한 쪽의 행렬의 리스트 사이즈를 추출하여 해당 사이즈를 for 반복문 실행을 통해 중첩 반복문에서 n번 행을 기준으로 필터와 패턴의
        열을 순차적으로 각각 곱하는 방식으로 구현합니다.

   3-3.epsilon:

       두 필터 연산의 점수 결과를 비교할 때 컴퓨터가 인식하기 어려운 미세한 차이가 존재할 때 임의로 지정한 가장 작은 수 (1e-9)를
       지정 후 두 필터의 점수의 차이가 해당 수 보다 작다면 그것을 동점 처리하고 구분 불가로 판정합니다.      
```
```
4. 결과 리포트

  4-1. 예외처리 항목

      사용자 입력 모드:
                      1.숫자가 아닌 값 입력
                      2.행렬 크기가 맞지 않는 경우
                      3.행렬 요소가 숫자가 아닌 경우
                      4.잘못된 메뉴 번호 입력

      json데이터 예외처리:
                        1.예외 상황	처리 내용 json 파일을 찾을 수 없는 경우
                        2.json 형식이 잘못된 경우
                        3.패턴 데이터가 없는 경우
                        4.필터 이름이 올바르지 않은 경우
                        5.패턴 이름 형식이 잘못된 경우
                        6.행렬 크기가 맞지 않는 경우
                        7.행렬이 2차원 구조가 아닌 경우
                        8.행렬 요소가 숫자가 아닌 경우
                        9.특정 패턴에 오류가 있는 경우

      실제 분석의 경우 for 반복문에서 이루어지고 예외가 발견되면, 해당 패턴은 분석하지 않으며 실패 내역만 남기고
      continue를 통해 다음 반복할 패턴으로 계속 분석합니다.                       


  4-2. FAIL 케이스 원인 분석

       총 6개 패턴 중 4개의 FAIL을 확인했습니다.
       size_5_1, size_13_2, size_25_1의 경우 점수 차이가 허용오차(epsilon) 이내여서 모두 UNDECIDED 판정에 의한 FAIL이 였습니다.
       그 외 size_5_2 패턴의 경우는 분석 불가로 인한 FAIL로, json 파일의 스키마와 내부 키와 값 그리고 행렬의 크기는 모두 정상적으로
       인식되었으나 size_5_2의 패턴의 input 값 행렬 리스트 요소에 문자열이 발견되어 분석 불가로 판정되어 MAC연산을 수행하지 않고
       다음 패턴으로 넘어가 정상적인 분석 절차를 이루었습니다.

  4-3. 성능 표 해석

        성능의 경우 한 패턴에 대해 두 필터 각 각 연산시간을 구한 후 패턴 행렬 크기 별로 리스트에 누적시킵니다. 누적된 값을 평균을
        내는 방식으로 성능을 알아보았습니다.

        5 x 5 의 평균 연산 시간 0.001115 밀리초, 연산 수 25

        13 x 13 의 평균 연산 시간 0.005183 밀리초, 연산 수 169

        25 x 25 의 평균 연산 시간 0.018300 밀리초, 연산 수 625


        시간 복잡도는, 연산 시 행렬 크기의 제곱에 비례하기에 시간 복잡도 O(N²)을 사용합니다.

        해당 시간 복잡도 기준으로 연산 수가 증가할 수록 연산 시간이 증가함을 알 수 있습니다.

        5 x 5 에서 25 x 25 로 증가했을 때 연산 수의 경우 25배, 평균 연산 시간은 약 16배로 증가를 확인되었습니다.

        이론적으로는 해당 시간 복잡도에 의해 연산 수 증가 비율과 실행 시간 증가 비율이 같아지는 것을 기대해 볼 수 있지만,

        만든 파이썬 프로그램에서 연산만 이루어진 것이 아닌, 함수 호출, 반복문 실행, 변수 처리와 같은 작업이 병행되어

        정확한 비율이 나오지 않을 수 있음을 생각해 볼 수 있습니다.
```
